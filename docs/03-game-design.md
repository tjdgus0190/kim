# 03. 게임 디자인 기획서 (메인 기획자)

## 1. 재미 검증 (Fun Check)

| 질문 | 답 | 판정 |
|---|---|---|
| 5초 안에 규칙을 이해하는가? | "작은 숫자 먹기, 큰 숫자 피하기, 같은 숫자는 대박" — 3문장 | ✅ |
| 매 순간 할 일이 있는가? | 항상 화면에 먹이/잭팟/위협이 동시에 존재하도록 스폰 분포 설계 | ✅ |
| 위험과 보상이 맞물리는가? | 잭팟 근처에 위협이 있을 때 "갈까 말까" 선택이 발생 | ✅ |
| 실력 개입 여지가 있는가? | 대시 타이밍, 가시 유인, 콤보 유지 | ✅ |
| 실패가 억울하지 않은가? | 위협 젤리는 나보다 느림(85%), 5초 추격 후 포기, 시작 무적 2초 | ✅ |
| 한 판 더 하고 싶은가? | 최고 점수/최고 숫자 기록, 짧은 세션(3~8분), 즉시 재시작 | ✅ |

**제외한 아이디어(재미 대비 복잡도 과다)**: 분열 조작, 아이템 상점, 멀티플레이, 스킬트리

## 2. 핵심 규칙 (Core Rules)
- 플레이어 숫자 `V`(항상 2의 거듭제곱, 시작 2)와 진행도 `P`(0 ≤ P < V)
- 젤리 `v`와 접촉 시:
  - `v < V` → **먹음**. `P += v`. `P ≥ V`가 되면 `V ×= 2`, `P -= 이전 V` (레벨업)
  - `v = V` → **잭팟 합체**. 진행도와 무관하게 즉시 `V ×= 2` (P 유지)
  - `v > V` → **먹힘 = 게임 오버**
- 가시: 반지름 46. 내 반지름이 가시의 1.1배를 넘으면(= V ≥ 32) 닿을 때 `V ÷ 2`, `P = 0` (사망 아님). 그보다 작으면 통과/은신 가능
- 위협 젤리가 가시에 닿으면 그 젤리도 반토막 → 역전 가능 (`TRAP!`, 보너스 점수)
- 목표: **2048 달성 = 클리어 연출**, 이후 무한 모드로 계속(4096, 8192 …)

## 3. 수치 로직

| 항목 | 공식 / 값 |
|---|---|
| 반지름 | `r = 16 + 7·log2(v)` (v=2 → 23, 2048 → 93) |
| 기본 속도 | `speed = 300 · (23 / r)^0.45` px/s (커질수록 느려짐) |
| 먹기 판정 | `거리 < max(r_큰 − 0.3·r_작은, 0.75·r_큰)` |
| 대시 | 0.22초간 속도 ×2.6, 쿨다운 2.5초 |
| 콤보 | 마지막 먹기 후 2초 이내 연속 시 콤보+1 (최대 10) |
| 점수 | `먹은 값 × 콤보`, 잭팟은 ×2 추가, TRAP 유도 시 +그 젤리 값 |
| 무적 | 시작 2초, 가시 피격 후 1초 |

## 4. AI 행동
| 상대 | 감지 거리 | 행동 |
|---|---|---|
| 위협 (v > V) | 420 + r | 플레이어 추격(자기 속도 × 0.85). 5초 추격 후 3초간 포기 |
| 잭팟 (v = V) | 260 + r | 도주(자기 속도 × 0.75) → 대시로 잡는 재미 |
| 먹이 (v < V) | 220 + r | 도주(자기 속도 × 0.55) |
| 그 외 | — | 1~3초마다 방향을 바꾸며 배회 |

## 5. 레벨 구성 (연속 진행형 스테이지)
월드 3000×3000 하나에서 **숫자 단계 = 스테이지**. 단계가 바뀌면 배너 + 배경 색 변화.

| 스테이지 | 숫자 구간 | 이름 | 신규 요소 / 난이도 포인트 |
|---|---|---|---|
| 1 | 2 ~ 8 | 얕은 접시 | 튜토리얼 구간. 먹이 많음, 위협 적음 |
| 2 | 16 ~ 64 | 젤리 숲 | **32부터 가시가 위험** — 가시 유인 전략 등장 |
| 3 | 128 ~ 512 | 깊은 배양액 | 위협 비중 증가, 이동 속도 감소로 대시 중요 |
| 4 | 1024 ~ 2048 | 황금 심연 | 위협 최다. 2048 달성 시 클리어 |
| ∞ | 4096 ~ | 무한 | 점수 경쟁 |

|---|---|---|---|---|---|---|---|

## 6. 게임 흐름
