- 구글/웹 검색 상단 노출 결과 기준으로 "무료 브라우저 게임 추천", "most popular browser games 2026", "io games / hypercasual trending" 키워드 조사
- 상단 노출 포털: CrazyGames(한국어 카테고리 포함), FRVR, MSN Games, itch.io(hypercasual 태그), 각종 "Best browser games 2026" 큐레이션 글

## 3. 인사이트
1. **"설치 없이 몇 초 안에 시작"** 이 웹 게임의 최대 가치. 튜토리얼 없이 이해되는 규칙이 필수.
2. 상단 노출작 대부분이 **한 판 3~10분** 의 짧은 세션 + "한 판만 더" 구조.
3. 가장 오래 살아남은 두 축은 **.io의 '먹고 커지기'** 와 **2048의 '합쳐서 진화'**. 두 장르 모두 숫자/크기라는 **직관적 성장 지표**를 가짐.
4. 모바일 웹 비중이 큼 → 터치 한 손 조작 지원 필요.
5. 실시간 멀티는 서버 비용/복잡도가 높음 → 1차 버전은 **싱글 + AI 블롭**으로 .io 감성 재현.

## 4. 기획팀 전달 제안
- **조합 추천: Agar.io(먹고 커지기) × 2048(같은 숫자 합치기)** + 보조 요소로 타워디펜스의 "함정 활용" 전략성 소량
- 타깃: 10~30대 캐주얼 유저, PC/모바일 브라우저
- 차별점: ".io 게임인데 크기가 아니라 **숫자**로 싸운다. 같은 숫자를 먹으면 즉시 2배!"
- KPI 가설: 첫 판 진입 5초 이내, 평균 세션 3판 이상, 첫 판 생존 2분 이상
