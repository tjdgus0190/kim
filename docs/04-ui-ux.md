# 04. UI/UX 디자인 명세 (디자이너)

## 1. 디자인 원칙
1. **게임 화면이 주인공** — HUD는 화면 모서리, 반투명, 최소 정보
2. **색 = 의미** — 빨강 위험 / 금색 잭팟 / 흰색 나. 색약 대비로 링 모양도 다르게(빨강=실선 맥동, 금=점선 회전)
3. **한 손 조작** — 모바일 대시 버튼은 엄지 영역(우하단) 72px

## 2. 컬러 토큰
| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#14121f` | 배경 |
| `--grid` | `rgba(255,255,255,.05)` | 격자 |
| `--panel` | `rgba(20,18,31,.72)` | HUD 패널 |
| `--text` | `#f4f1ff` | 기본 글자 |
| `--danger` | `#ff4d6d` | 위협 링, 게임오버 |
| `--gold` | `#ffd23f` | 잭팟, 콤보, 클리어 |
| `--accent` | `#7cf5c4` | 버튼, 진행 바 |
| `--spike` | `#8be04e` | 가시 |

폰트: Google Fonts **Jua**(타이틀·숫자, 말랑한 한글) + 시스템 산세리프

## 3. 화면 구성

### 3.1 타이틀
```
┌──────────────────────────────┐
│         MERGE JELLY          │  ← 출렁이는 로고
│    같은 숫자를 먹으면 2배!     │
│                              │
│  🟢 작은 숫자 → 먹어요          │
│  🟡 같은 숫자 → 즉시 합체 ×2    │
│  🔴 큰 숫자 → 도망쳐요!         │
│                              │
│        [ ▶ 시작하기 ]          │
│   최고 점수 0 · 최고 숫자 2    │
│  마우스로 이동 · 클릭/Space 대시 │
└──────────────────────────────┘
```

### 3.2 플레이 HUD
```
┌─────────────────────────────────────┐
│ 점수 1,240        [ 64 ]        ⏸ 🔊 │
│ 최고 3,100   ███████░░░ 40/64        │
│                COMBO ×4             │
│                                     │
│              (게임 화면)              │
│                                     │
│ 스테이지 2 · 젤리 숲            (⚡) │ ← 대시 버튼(쿨다운 링)
└─────────────────────────────────────┘
```
- 중앙 상단 **현재 숫자 타일**: 2048 팔레트 색, 레벨업 시 팝 애니메이션
- 진행 바: 다음 숫자까지 `P / V`
- 콤보: 2 이상일 때만 노출, 금색, 숫자 커질수록 크게

### 3.3 게임오버
```
┌──────────────────────────────┐
│          꿀꺽! 😵              │
│    256 젤리에게 먹혔어요         │
│                              │
│   점수 4,820   (NEW BEST!)    │
│   최고 숫자 128  ·  2:41       │
│   먹은 젤리 37개               │
│                              │
│        [ ↻ 다시하기 ]          │
│     Space / Enter 로 재시작     │
└──────────────────────────────┘
```

### 3.4 클리어 배너 (2048 도달)
- 일시정지 없이 화면 중앙 3초 배너: "🏆 2048 달성! 무한 모드 시작" + 금색 파티클 폭발

## 4. 인터랙션 & 피드백
| 이벤트 | 시각 | 청각 |
|---|---|---|
| 먹기 | 작은 파티클 6개, `+v` 플로팅 | 뽁 (콤보마다 반음↑) |
| 잭팟 합체 | 금색 파티클 24개, `MERGE! ×2`, 화면 흔들림 6px | 3음 화음 |
| 레벨업 | 숫자 타일 팝(1.3배), 스테이지 변경 시 배너 | 상승음 |
| 가시 피격 | 초록 파티클, 화면 흔들림 10px, `-½` | 둔탁한 음 |
| TRAP 성공 | `TRAP!` 금색 텍스트 | 반짝음 |
| 사망 | 슬로모션 0.4초 후 결과창 | 하강음 |

## 5. 반응형
- 캔버스는 화면 전체, devicePixelRatio 대응
- 600px 이하: HUD 글자 축소, 대시 버튼 노출(터치 기기에서만)
- 카메라 줌: 내 젤리가 커질수록 줌 아웃 → 시야 확보
